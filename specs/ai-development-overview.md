# AI-Assisted Development Overview

## Purpose

Artificial intelligence was used throughout the development of Cinephile as a software engineering assistant rather than as an autonomous developer.

The goal of using AI was to improve productivity, gain a better understanding of unfamiliar technologies, and receive feedback on implementation decisions while maintaining ownership of the final solution.

Throughout the project, every significant implementation was reviewed, tested, and modified where necessary before being incorporated into the application.

---

# AI Tools Used

## ChatGPT

ChatGPT was the primary AI assistant used throughout the project.

It was used to:

- discuss architecture and project planning
- explain ASP.NET Core concepts
- learn Entity Framework Core
- review React components
- debug backend and frontend issues
- improve UI implementation
- explain authentication and JWT
- design the gamification system
- generate and review unit tests
- create Cypress end-to-end tests
- assist with CI/CD configuration
- review deployment issues
- improve project documentation

Rather than requesting complete solutions, interactions were generally focused on solving individual implementation problems or reviewing existing code.

---

## Claude

Claude was used as a secondary AI assistant.

Its primary role was to provide alternative explanations and compare different implementation approaches for selected technical challenges.

Examples included:

- reviewing architectural decisions
- suggesting React improvements
- discussing backend design
- comparing testing strategies

Using multiple AI tools occasionally helped identify different approaches before selecting the most appropriate solution.

---

## v0

v0 by Vercel was used during the UI design stage.

The initial interface designs generated by v0 were used as inspiration for the application's visual appearance.

These designs were then integrated into the React application and customised to fit the project's functionality, branding, and component structure.

The application's behaviour, routing, business logic, and integration with the backend were implemented manually.

---

# Development Workflow

AI assistance was used throughout the entire software development lifecycle rather than during a single phase.

Typical workflow:

1. Plan the feature.
2. Discuss possible implementation approaches.
3. Implement the feature manually.
4. Debug any issues encountered.
5. Review and refactor the implementation.
6. Write tests.
7. Update documentation.

This iterative process helped ensure that AI suggestions supported development rather than replacing it.

---

# Examples of AI-Assisted Tasks

Examples of areas where AI provided useful assistance include:

## Learning New Technologies

The project introduced several technologies that were new to the developer, particularly ASP.NET Core Web API and Entity Framework Core.

AI was frequently used to explain concepts such as:

- dependency injection
- middleware
- JWT authentication
- Entity Framework relationships
- migrations
- LINQ queries
- model validation

These explanations helped build understanding before implementation.

---

## Backend Development

During backend development AI assisted with:

- controller structure
- DTO design
- service organisation
- authentication
- API design
- Entity Framework configuration
- debugging database issues

One of the more challenging parts of development was integrating TMDB while keeping the application's own data separate from external movie information.

AI helped evaluate different approaches before the final implementation was chosen.

---

## Frontend Development

AI was used to review:

- React components
- state management
- routing
- responsive layouts
- reusable components
- UI improvements
- accessibility

Suggestions were incorporated where appropriate while maintaining the existing component structure.

---

## Gamification

The gamification system evolved through multiple iterations.

AI discussions focused on topics such as:

- XP allocation
- achievement progression
- level thresholds
- viewing streak calculations
- toast notifications
- balancing user rewards

The final implementation was refined through testing and incremental improvements.

---

## Testing

AI assisted in developing a comprehensive testing strategy.

This included guidance on:

- backend unit tests using xUnit and Moq
- frontend component testing using Vitest
- React Testing Library
- Cypress end-to-end testing
- GitHub Actions CI workflows

Tests were written and expanded alongside existing project functionality to improve confidence before deployment.

---

## Deployment

During deployment AI was used to troubleshoot issues relating to:

- Azure App Service
- Vercel
- environment variables
- CORS configuration
- production API URLs
- CI/CD pipelines

These discussions helped resolve deployment-specific issues that differed from local development.

---

# Human Review

Although AI provided suggestions throughout development, all outputs were reviewed before being incorporated into the project.

Typical review steps included:

- understanding the proposed solution
- adapting code to fit the existing architecture
- testing functionality locally
- reviewing edge cases
- verifying compatibility with existing features

Many suggestions were modified before being committed to the repository.

---

# Limitations of AI

AI assistance was treated as a source of ideas and technical guidance rather than an authoritative source.

Some suggestions required modification to:

- fit the existing architecture
- improve readability
- satisfy project requirements
- resolve implementation-specific issues

This reinforced the importance of validating AI-generated solutions rather than accepting them unchanged.

---

# Summary

AI significantly improved the development process by providing explanations, debugging assistance, implementation guidance, and documentation support.

However, software design decisions, implementation choices, integration, testing, deployment, and final verification remained the responsibility of the developer.

The combination of AI-assisted development and manual review helped accelerate development while maintaining understanding and ownership of the final application.

# AI Prompt Log

## Purpose

This document provides an overview of how artificial intelligence was used throughout the development of Cinephile.

Rather than using AI to generate the entire application, AI was used as a software engineering assistant throughout the project lifecycle. Typical uses included architecture discussions, debugging, implementation guidance, testing, deployment, documentation, and code review.

The prompts recorded in this folder are representative of the actual development workflow and are organised chronologically by development phase.

Each prompt demonstrates how AI supported decision making while leaving implementation, integration, testing, and final verification to the developer.

---

# AI Tools

During development three AI tools were used.

## ChatGPT

Primary development assistant.

Used for:

- Architecture discussions
- ASP.NET Core guidance
- Entity Framework Core
- React development
- Debugging
- Gamification
- Testing
- CI/CD
- Deployment
- Documentation

---

## Claude

Secondary assistant.

Used for:

- Alternative implementation ideas
- Code review
- Design discussions
- Technical explanations

---

## v0

Used only during UI design.

v0 generated the initial interface design, which was then customised and integrated into the existing React application.

# Prompt Style

The prompts recorded in this folder focus on realistic software engineering activities including:

- planning
- architecture
- implementation
- debugging
- reviewing code
- testing
- deployment
- documentation

The prompts intentionally avoid unrealistic requests such as asking AI to generate the complete application.

Instead, they demonstrate an iterative development process where AI acted as a collaborative engineering assistant.

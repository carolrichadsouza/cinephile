# Frontend Development

This document contains representative prompts from the frontend development phase of Cinephile.

During this stage, AI was primarily used to review React components, explain implementation approaches, improve the user interface, troubleshoot frontend issues, and integrate the visual design generated using v0.

The application's functionality, routing, state management, and component integration were implemented by the developer.

---

## Prompt 1 :  Integrating the UI Design

### Prompt

> I've generated an initial UI using v0, but I want to integrate it into my existing React application rather than replacing everything. What's the best approach?

### Why I asked

The visual design generated by v0 matched the style I wanted, but I already had an existing React project and needed to incorporate the design without disrupting the application's architecture.

### Summary of AI Response

The recommendation was to:

- Keep the existing routing and application structure.
- Reuse only the visual components from the generated design.
- Separate styling from business logic.
- Refactor the generated code into reusable React components where appropriate.

This approach allowed the application's functionality to remain unchanged while improving its visual design.

## Prompt 4 : Community Reviews

### Prompt

> I want users to see reviews from other users on the movie details page, but I don't want the page to become cluttered. What would be a good approach?

### Why I asked

As more reviews were added, displaying all of them directly on the page reduced readability.

### Summary of AI Response

The suggested approach was to:

- Display only the first few reviews initially.
- Include a "See All" option.
- Open the remaining reviews inside a dialog or modal.

This became the final implementation.

## Prompt 6 : Theme Switching

### Prompt

> I'm implementing light and dark mode. What's the best way to apply theme switching consistently across my React application?

### Why I asked

Theme switching was one of the project's selected advanced requirements, so it needed to work consistently across every page.

### Summary of AI Response

The discussion focused on:

- Centralising theme management.
- Applying themes at the application level.
- Persisting the user's preference.
- Ensuring all components respected the selected theme.

This resulted in a consistent experience across the application.

## Prompt 7 : Component Reusability

### Prompt

> I'm noticing similar UI appearing across multiple pages. How should I decide whether something should become a reusable component?

### Why I asked

As the project grew, duplicated UI became harder to maintain.

### Summary of AI Response

The recommendation was to extract repeated interface elements into reusable components where they shared behaviour or styling.

Examples included:

- Movie cards
- Rating controls
- Buttons
- Dialogs
- Navigation components

This improved maintainability while reducing duplicated code.

## Prompt 9 : Frontend Debugging

### Prompt

> My frontend isn't displaying the updated data after an API request. How can I determine whether the issue is in React, the API, or the backend response?

### Why I asked

Some issues required identifying whether the problem originated from state management, API communication, or backend behaviour.

### Summary of AI Response

Rather than immediately changing code, AI suggested checking:

- Browser network requests.
- API responses.
- React state updates.
- Component rendering.
- Backend logs.

This debugging process helped isolate issues more efficiently.
